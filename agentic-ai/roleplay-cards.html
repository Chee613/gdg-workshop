Be the agent

A 4-minute role-play, run just before the loop slide. The room watches a person do exactly what an agent does: read, choose a tool, act, check, and stop for the boss.

Roles

  • The agent (a volunteer): holds the goal card, rules card, instructions card and notebook. Cannot do anything by themselves.
  • The tools helper (Faiz or a volunteer): holds the 3 tool cards face up on a table, and the 4 answer cards hidden.
  • The boss (someone in the audience): holds the boss card and gives the final yes.
  • You narrate each move out loud: "read… choose… act… check."

If it goes off script

  • The agent asks for a tool that isn't on a card: the helper gives the "No such tool" card.
  • The agent tries to post straight away: the boss says "Not yet. Where's the QR code?"
  • The agent forgets the notebook: the boss asks "What time was the last meetup?"

Then say, and press → to the loop slide

"Three laps. Every lap: read, choose, act, check. Nobody told the agent the order: the tool answers did. And the agent never touched a room or a form. The tools did."

Agent · how you work

You can't do anything yourself.

  1. Read your notebook and the instructions.
  2. Choose one tool.
  3. Hand that tool card to the tools helper.
  4. Write the answer in your notebook.
  5. Check the goal. Not done? Go round again. Done? Ask the boss.
